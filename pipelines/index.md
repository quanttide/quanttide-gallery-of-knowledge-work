# 管道案例

每条管道一件案例：从一处流到另一处，写明需求、意图、规格与实现。

每件按四节写：需求说为什么做、给谁做、做成什么算成；意图说设计取舍与已知粗糙处；规格说阶段、输入输出与判据；实现说落在哪些文件、怎么跑。规格旁边同名放一份可运行的 `.yaml`，它是规格的一种形式化表达，不是另一份正本；没有 YAML 的，规格以散文为准。
