# 流程案例

每条流动关系一件案例：从一个产物流到另一个产物，附其目标、步骤与验收。

工作流案（多步管道）按工作流自己的名字立件，一步一节、节内带该步的验收；流动关系案（一次转变）按「从 X 到 Y」立件，验收合成一节。

工作流案旁边同名放一份可运行的 `.yaml`：**案例是给人看的正本，YAML 是机器执行的形态**，两份同改。
