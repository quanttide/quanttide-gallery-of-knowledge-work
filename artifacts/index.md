# 产物案例

每件具体产物一件案例：抽象概念在这个领域落成的一件实物，附其目标、流程与验收。

## 清单

- [语境](context.md)：驱动型·无时态——驱动层——沉淀、修订、加载。
- [日志](journal.md)：陈述型·现在×事件类——状态线索——捕获、整理、分流、清空。
- [档案](profile.md)：陈述型·现在×语义类——沉淀层——转入、组织、转出。
- [意图](intention.md)：陈述型·未来×自我类——方向层——转入、组织、归档。
- [洞察](insight.md)：陈述型·未来×语义类——认知层——转入、组织、修订。
- [路线图](roadmap.md)：陈述型·未来×事件类——排序层——转入、组织、勾销。
- [规格](specification.md)：程序型——规范文本的写法——命名、归纳、生长、落文、精简、检验。
- [手册](handbook.md)：程序型·法律·人类友好——集合载体——注册、维护、发布。
